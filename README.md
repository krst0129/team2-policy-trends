# 과학기술정책 동향 조사 대시보드

키워드와 조사기간을 넣고 **조사 및 발간**을 누르면 국내·해외 자료를 조사합니다. 링크 검증을 통과한 자료만으로 주제별 그래프, 조사자료 목록(CSV), 보고서(hwpx·PDF)를 만듭니다. 기획은 [기획안.md](기획안.md)를 보세요.

## 시연 영상 (약 30초)
키워드 입력 → 조사 및 발간 → 진행률 → 주제 그래프 클릭 필터 → hwpx 내보내기 100% → 공개 결과 페이지 → PR 검토 대기

## 처음 한 번 준비
1. Node.js 20 이상을 설치합니다.
2. Claude Code에 로그인합니다. Claude 데스크톱 앱에 들어 있는 CLI를 써도 됩니다.
   ```powershell
   & "$env:LOCALAPPDATA\Claude-Data\claude_pzs8sxrjxfjjc\claude-code\<버전>\<해시>\claude.exe" auth login
   ```
   PATH에 `claude`가 있으면 `claude auth login`만 하면 됩니다. 대시보드는 CLI를 자동으로 찾습니다.
3. `.env.example`을 `.env`로 복사하고 API 키를 넣습니다(네이버, Google). 키가 없으면 그 출처만 건너뜁니다.

## 실행
```powershell
npm start
```
브라우저에서 http://localhost:3000 을 엽니다.

## 쓰는 법
1. 오른쪽 위에서 **실행자**(김은성/김채림)를 고릅니다.
2. 키워드, 조사기간(최대 1년), 출처를 정합니다.
3. **상대 담당 영역 처리**를 고릅니다.
   - **직접 조사**: 혼자서 국내·해외를 모두 조사합니다.
   - **상대에게 넘기기**: 내 영역만 조사하고, 상대 영역은 넘깁니다. 진행 상태의 **넘김 요청 Issue 만들기**를 누르면 결과를 GitHub에 올리고 Issue로 알립니다.
4. 넘겨받은 사람은 **GitHub 동기화** → 첫 화면의 **이어받기**를 누릅니다.
5. 진행 상태 카드에서 0~100% 진행률과 단계(자료 수집 → 링크 검증 → 주제 분류 → 보고서 작성 → 발간)를 확인합니다.
6. 발간되면 다음을 할 수 있습니다.
   - 그래프를 눌러 목록 거르기
   - **CSV 파일 내보내기**
   - **hwpx / PDF 내보내기**: 발간 때 미리 만들어 두어서 바로 내려받습니다.
   - **결과 웹페이지(내보내기 도구)**: 서버 없이 열리는 HTML 한 장입니다. 결과 화면과 hwpx·PDF·CSV 내보내기, 인쇄가 모두 들어 있어서 이 파일만 팀원에게 주면 됩니다.
   - **GitHub에 올리기**

## 거짓 방지 (링크 검증기)
아래 세 가지를 모두 확인한 자료만 목록·그래프·보고서에 들어갑니다.
1. 링크를 직접 다시 열었을 때 정상으로 열린다.
2. 페이지에 자료 제목과 키워드가 실제로 있다.
3. 원문에 적힌 게시일이 조사기간 안에 있다.

봇 접속을 막는 사이트, 날짜를 확인하지 못한 자료는 **검증 보류** 탭에만 보여 줍니다. 보고서 문장은 근거 자료 번호가 있어야 하고, 근거에 없는 숫자나 인용이 있으면 자동으로 뺍니다.
